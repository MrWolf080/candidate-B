# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки и получает предполагаемую тему и черновик ответа. AI помогает с первичной обработкой, но менеджер проверяет результат и сам решает, что отправить клиенту.

## Требования и запуск

Нужен Node.js 20 или новее. Внешние зависимости и API-ключи не нужны.

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно изменить через переменную `PORT`.

## Запуск тестов

```sh
node --test server.test.mjs
```

Тесты используют встроенный `node:test` и запускают локальный HTTP-сервер на свободном порту. Проверяются валидация ввода, битый JSON, успешный ответ и все сценарии отказа имитатора.

## Что изменено

- `POST /api/triage` принимает только JSON-объект с непустой строкой `text`. Пустое, отсутствующее, нестроковое значение и некорректный JSON возвращают HTTP 400 с `{"status":"invalid_input"}`.
- Ожидание AI ограничено 300 мс. Таймаут прерывает вызов через `AbortController`; исключения провайдера, невалидный JSON, неизвестная тема и пустой черновик обрабатываются одинаково.
- Успешный ответ: `{"status":"ready","topic":"delivery|pricing|other","draft":"..."}`.
- При сбое API возвращает HTTP 200 и `{"status":"manual_review","topic":null,"draft":null}`. Это ожидаемый сценарий ручной обработки, а не ошибка HTTP-сервера.
- Интерфейс проверяет пустой ввод, показывает тему и черновик, блокирует повторную отправку на время запроса. Перед новым разбором старый результат очищается. При сбое менеджер получает инструкцию провести разбор вручную.
- Поведение выданного `mock-ai.mjs` не менялось.

## Сценарии имитатора

Добавьте в текст заявки один из маркеров:

- `[timeout]` — задержка дольше лимита;
- `[error]` — ошибка AI-провайдера;
- `[bad-json]` — ответ не является JSON;
- `[bad-topic]` — недопустимая тема;
- `[empty-draft]` — пустой черновик.

Обычный текст обрабатывается успешно. Слово «доставка» даёт тему `delivery`, «цена» или «стоимость» — `pricing`.

## Где проверяется ответ AI и что происходит при сбое

Проверка находится в `server.mjs`: `classifyWithTimeout()` ограничивает время ожидания, а `validateModelResult()` проверяет JSON, допустимую тему и непустой черновик. При таймауте, исключении или неподходящем результате сервер возвращает `manual_review` с `topic` и `draft`, равными `null`. На странице старый результат очищается, а менеджеру предлагается вручную определить тему и подготовить ответ.

## Польза для менеджера и метрика

AI сокращает время первичной классификации и подготовки ответа; пользу можно измерять по медианному времени обработки заявки и доле черновиков, принятых без существенных правок.

## Использование AI

При реализации использовался AI-помощник. Перед сдачей выполните `node --test server.test.mjs` и вручную проверьте страницу с обычным текстом и каждым маркером сбоя.
